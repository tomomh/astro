# Introduction

Welcome to the Astro + Sanity Demo documentation.

## Overview

This project demonstrates how to build a modern blog using:

- **Astro** - A fast, content-focused web framework
- **Sanity** - A flexible headless CMS
- **MDX** - Enhanced Markdown with component support

## Features

- Static site generation (SSG)
- Content Collections for local MD/MDX files
- Sanity CMS integration for dynamic content
- Responsive design
- SEO optimized

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables
4. Run development server: `npm run dev`

## Project Structure

```
src/
├── components/     # Reusable UI components
├── content/        # MD/MDX content collections
│   ├── blog/       # Blog posts
│   └── docs/       # Documentation
├── layouts/        # Page layouts
├── lib/            # Utilities (Sanity client)
├── pages/          # Route pages
└── styles/         # Global styles
```
